# Moonlight RT 0.2.1

[下载安装包](https://github.com/john-shalu/moonlight-rt81/releases/latest) · [English](README.md)

适用于已经解锁、能运行第三方 ARM 桌面程序的 Windows RT 8.1 / Surface 2。按官方 Moonlight 的深色主机卡片、应用网格和独立设置页布局，使用已在此设备验证的原厂 H.264 硬解与键鼠触控实现。这是社区原生适配版，不是官方 Moonlight Qt 二进制，也不包含完整 Qt 功能集。

## 安装或升级

1. 将整个运行包完整解压到平板或 U 盘，不要直接在 ZIP 内运行。
2. 退出原来的 Moonlight 测试版。
3. 双击 `Install-Moonlight.cmd`。程序会安装到当前用户的 `%LOCALAPPDATA%\Programs\MoonlightRT81`，创建桌面和开始菜单里的 **Moonlight RT** 快捷方式，不要求管理员权限。
4. 以后从快捷方式打开即可，U 盘可以拔走。

原来的配对身份、主机证书和设置仍在 `%LOCALAPPDATA%\MoonlightRT81`。本版会读取旧版保存的电脑地址，不需要重新配对。不要删除这个个人配置目录。

若暂时不想安装，也可以双击 `Start-Moonlight.cmd`，或直接运行 `MoonlightRT81.exe`；完整文件夹应保持在一起。安装前会做只读的系统接口与文件校验。卸载可使用控制面板，或运行安装目录内的 `Uninstall-Moonlight.ps1`；卸载脚本要求输入 YES 确认，并保留个人配置。

## 0.2.1 输入与鼠标修复

- 视频区域隐藏本机指针，显示视频里的远端指针，避免两套指针叠在一起。
- 桌面/触控模式沿用绝对位置操作。玩游戏时，点右上角 ☰ → **游戏鼠标：开**，或按 **Ctrl+Alt+Shift+M** 切换。游戏模式捕获物理鼠标，发送相对移动，不再受本机屏幕边缘限制。原始鼠标接口不可用时会使用回中方式。
- 再按相同快捷键可回到桌面模式、释放物理鼠标。触摸本地菜单、切换窗口、离开程序或断开时会释放捕获。触屏仍按屏幕位置点击/拖动，切回物理鼠标时点画面可重新捕获。
- 设置中的“默认游戏鼠标”可以保存以后串流的默认模式；串流菜单里的开关只改变本次会话。
- 输入发送和日志写盘改在后台。每次连接完成后才开放输入；断开时清理按住的键、按钮和未发送输入，再关闭协议库。界面不等待输入库或后台工作线程。
- 右上角菜单和窗口关闭保持本地处理。若用户主动关闭时后台仍卡住，约5秒后退出本客户端，避免必须到任务管理器结束。

设备所有者已实测 0.2.1，并确认这些问题修复后使用正常。未取得原卡顿时的线程堆栈，因此仍不把某一处风险认定为唯一根因。

## 日常使用

- 首页选择电脑，进入应用列表，再点击 **Desktop** 或其他应用，即可开始串流。旧版保存的电脑会自动出现在首页。
- 新电脑点“添加电脑”，输入局域网 IP 或主机名，HTTP 端口通常保留 `47989`。没有本地配对记录时，会显示四位 PIN；在 Sunshine 网页的 PIN 页面提交这个数字。
- 右键或长按电脑卡片，可以编辑地址、名称、端口、重新配对或从列表移除。移除列表项不会删除主机上的内容或个人配对证书。
- 全屏串流时，点右上角 **☰** 可打开断开与窗口切换菜单。键盘快捷键 `Ctrl+Alt+Shift+Q` 断开串流。断开后主机上的应用保持运行。
- 触屏以绝对位置鼠标点击和拖动方式操作；物理键盘、鼠标在视频画面取得焦点后转发。普通键通过虚拟键码发送，中文输入可在被控电脑切换输入法。

## 设置

默认 **1280×720 / 30 FPS / 5 Mbps**，全屏与声音开启。可以选择 720p 或 1080p、30 或 60 FPS、3～30 Mbps，以及声音与默认游戏鼠标开关。设置保存后，下次串流生效。

720p/30 FPS 是当前实机验证过的配置；更高分辨率、帧率和码率会提高性能与网络要求，需要在平板上测试。视频始终使用 H.264 硬件解码，音频为立体声。不提供无法使用的 HEVC、AV1、HDR 或 YUV444 选项。

本版支持手动添加和记住多台电脑、应用卡片与可取得的封面。尚未实现自动局域网发现、手柄、剪贴板、原生多点触摸或本地输入法合成文本。触控操作按鼠标处理。

## 帮助与日志

进入“设置 → 帮助与诊断”，可查看日志、打开日志文件夹、运行本地自检，或点击“开源许可”查看 GPLv3。日志和个人配置保存在 `%LOCALAPPDATA%\MoonlightRT81`。

本地自检播放包内三段自生成 H.264 动画，并执行身份保存与 Opus 编解码检查，不连接主机；音频编解码检查不播放测试音。它不替代实际串流和扬声器测试。

输入日志记录焦点、后台发送数量、重置和丢弃数量、最慢API耗时，以及卡顿时的界面心跳，不记录具体按键或输入文字。后台发送成功也不等于主机确认执行。遇到问题请保留最新 `moonlight-日期-时间.log`；启动失败时另保留 `compatibility-result.json`。配对私钥使用当前 Windows 用户的 DPAPI 保护，程序不自动上传日志。

程序仍是未签名的 ARM32 桌面程序；请沿用当前已能运行 0.1.1 的解锁环境，不需要更换系统 DLL、驱动或启动器。

## 验证情况

- 用户已在 Surface 2 的 Windows RT 8.1 上确认 0.1.1 视频、鼠标、键盘与触摸输入正常。
- 用户已确认0.2界面基本正常、视频音频流畅；但报告双指针、游戏鼠标碰边，以及启动/重连时可能卡住输入和本地控制。0.2.1针对这些问题调整输入、日志和会话收尾。
- 设备所有者已确认 0.2.1 实际使用正常。公开包在同一串流、音频和输入代码上，仅增加编译路径清理、帮助页 GPL 许可说明与查看按钮，以及发布文档。公开重编译包完成编译与静态检查，没有另做一次平板复测。
- 本版无窗口离线测试使用真实输入派发模块和模拟传输端：发送端暂停时仍可入队10000个事件，50轮启动/结束清理、按键释放、溢出重置和大幅相对移动拆分均通过。测试没有读取真实输入设备或连接网络。
- 历史同源码后端的 x64 测试完成360帧本地 DXVA 硬解与显示、Opus/DPAPI、模拟正确/错误配对及 TLS 证书校验，并与真实 Sunshine 完成串流。具体版本和范围见 `validation/`，不把历史结果当作本版全部功能实测结论。

## 源码构建

对应源码 ZIP 附带固定依赖源码、界面/资源/安装脚本、许可证和验证记录，不含个人配置、配对密钥或运行日志。

现代 Windows x64 上使用 PowerShell 7，在较短路径中解压，安装 Ninja 并加入 PATH，然后运行：

```powershell
./Get-Sources.ps1
./Get-BuildTools.ps1
./build.ps1
```

输出 `work/build-armv7/MoonlightRT81.exe`。`./build.ps1 -Architecture x86_64` 只供开发验证，不能在 Windows RT 上使用。精确提交与工具版本见 `pins.json`；当前源码与二进制的校验值见 `build-manifest.json`。

源码 ZIP 已含依赖时 `Get-Sources.ps1` 会复用现有目录。依赖为 Moonlight common-c、MbedTLS 3.6.7、Opus 1.5.2、pugixml 1.15；程序使用 Win32/GDI、Media Foundation、D3D11 和系统 MSVCRT，不需要安装 Qt、FFmpeg、UCRT 或额外运行库。
